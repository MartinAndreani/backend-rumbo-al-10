# Backend · rumbo al 10

Página de estudio para el parcial de Backend de Aplicaciones del 10 de noviembre de 2026. Incluye prioridades de código y teoría, calendario según bloques de estudio, inventario de las guías 2–6, cinco dominios de simulacro y un control de preparación que guarda el progreso en el navegador.

Abrí `index.html` en un navegador o serví esta carpeta como sitio estático. Los PDF, ZIP y proyectos originales se conservan en la carpeta local `Backend` y no se copian a este repositorio.
