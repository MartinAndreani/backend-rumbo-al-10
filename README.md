# Backend · plan de estudio al 18 de noviembre de 2026

Sitio de estudio para el examen de Backend de Aplicaciones de la UTN FRC: lecturas dirigidas de los apuntes de las clases 04–13, un ejercicio núcleo por bloque, simulacros, checklist y temporizadores. El sábado 14 se trabaja la base de los bloques 2–6; el domingo 15 se hacen los simulacros. Lunes y martes quedan para corregir después del trabajo.

**Sitio publicado:** https://martinandreani.github.io/backend-rumbo-al-10/

El repositorio es público para poder servir el plan y los materiales mediante GitHub Pages.

La página principal es `index.html`. Los PDFs, ZIP y dos README enlazados desde ella están incluidos en sus rutas relativas y funcionan desde el sitio publicado. El progreso, las notas y los temporizadores se guardan en el almacenamiento local de cada navegador; no se sincronizan entre dispositivos.

Material académico original: cátedra de Backend de Aplicaciones, UTN FRC. El plan y las explicaciones breves son una organización personal para preparar el examen.
